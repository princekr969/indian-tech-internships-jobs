## ✅ Eligibility & Selection

### Eligibility
- 🎓 **2027 Bachelor's graduate** in CS / IT / related
- 📅 **Full Stack: React/Next.js + Node/Python + PostgreSQL + cloud**
- 💻 **1+ project with AI/LLM integration a plus**
- 🌍 **Comfort with AI tools (Cursor, Claude Code, Copilot)**
- 📊 **6.0+ CGPA** typical

### Selection Process

| Stage | Format | What It Tests |
|---|---|---|
| **1. Application** | Portal / LinkedIn | Resume + projects + GitHub |
| **2. Take-home assignment** | Async | Full-stack build (3-5 days) |
| **3. Technical Interview (1-2 rounds)** | Virtual | Full-stack + DSA + projects |
| **4. HR Discussion** | Virtual | Role expectations + stipend |
| **5. Offer** | Via recruiting | PPO based on intern performance |
