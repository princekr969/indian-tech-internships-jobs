## ✅ Eligibility & Selection

### Eligibility
- 🎓 **2027 Bachelor's or Master's graduate** in CS / IT / AI/ML / Data Science
- 📅 **Combined aggregate ≥ 7.0 CGPA** (strict cutoff)
- 💻 **DSA + Java/C/C++ + cloud platforms (AWS/Azure/GCP)**
- 🚫 **No active backlogs** at time of application
- 🌍 **No prior full-time experience**

### Selection Process

| Stage | Format | What It Tests |
|---|---|---|
| **1. Application via Workday** | Resume + cover letter | ATS keyword match + projects |
| **2. Online Assessment** | HackerRank / HackerEarth | DSA + coding (2-3 problems) |
| **3. Technical Interview (1-2 rounds)** | Virtual (CoderPad) | DSA + projects + system design |
| **4. Hiring Manager Round** | Virtual | Behavioral + role fit |
| **5. Offer** | Via Workday portal | PPO based on intern performance |

**Total timeline:** 4-8 weeks.
