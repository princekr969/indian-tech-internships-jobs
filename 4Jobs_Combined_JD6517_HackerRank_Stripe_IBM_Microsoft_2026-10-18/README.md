### 🟢 Job 1: HackerRank — SDE I (Intern), Bengaluru

**Snapshot:**
| Field | Value |
|---|---|
| Stipend | ₹65,000–75,000/month |
| Location | Bengaluru (Hybrid) |
| Batch | 2027 / 2028 |
| Apply | [lnkd.in/gJKKZA3Z](https://lnkd.in/gJKKZA3Z) · [lnkd.in/gqUqrRG6](https://lnkd.in/gqUqrRG6) |

**What You'll Do:**
- Build features on HackerRank's core assessment platform (TypeScript + Node.js + React)
- Develop AI-driven features for candidate evaluation
- Improve platform performance and reliability
- Work with senior engineers on full-stack services

**Must-Have Skills:**
- Strong in one of Python / JavaScript / TypeScript / Java
- DSA — Medium LeetCode (Arrays, Strings, HashMap, Trees)
- 1 full-stack project on GitHub
- SQL fluency (joins, indexing)

**Eligible Batches:** 2027 ✅, 2028 ✅ (others ⚠️ FTE only or ❌ too early)
**Eligible Branches:** CS/IT/AI/ML = ✅, ECE/EE/DS = ⚠️, Math = ❌

**Interview Difficulty:** Medium (3/5) — 2 Medium LeetCode + 1 system design + 1 behavioral

**Why HackerRank:** You already use their platform; building it is meta and fun. Strong PPO pipeline. ~₹70K/mo is above-average for Indian intern.

**Source:** Swadesh Kumar LinkedIn, 18 Oct 2026.

### 🟣 Job 2: Stripe — SWE I (Intern), Bengaluru

**Snapshot:**
| Field | Value |
|---|---|
| Stipend | Not disclosed (est. ₹4-6L/mo US-equivalent) |
| Location | Bengaluru (Hybrid) |
| Batch | 2028 / 2027 |
| Apply | [lnkd.in/d97gRkgd](https://lnkd.in/d97gRkgd) · [lnkd.in/gwS-NF8S](https://lnkd.in/gwS-NF8S) |

**What You'll Do:**
- Build features on Stripe's core payments platform (Ruby + Ruby on Rails + PostgreSQL)
- Develop internal tools in TypeScript + React
- Improve platform reliability (99.999% SLA)
- Write design docs and participate in rigorous code reviews (3-5 reviewers per PR)
- Cross-timezone collaboration with SF / Dublin / Singapore engineers

**Must-Have Skills:**
- Hard-level LeetCode (Trees, Graphs, DP, Tries, Union-Find)
- Strong in one of Ruby / Python / Java / C++
- System design basics (URL shortener, Rate Limiter, Payment Gateway)
- PostgreSQL internals (indexes, query plans)
- 200+ LeetCode (75+ Medium/Hard) + 1 production-grade full-stack project

**Eligible Batches:** 2027 ✅, 2028 ✅ (others ⚠️ FTE only or ❌ too early)
**Eligible Branches:** CS/IT/AI/ML = ✅, ECE/EE/DS = ⚠️, Math = ❌

**Interview Difficulty:** Very Hard (4-5/5) — 3-5 rounds, Hard LeetCode + system design + project deep-dive + behavioral. **Google/Meta tier.**

**Why Stripe:** One of the most prestigious intern brands in India. ~$95B valuation. PPO rate ~80%+. Work on the core payments platform that processes $1.4T annually.

**Source:** Mala Srivastava LinkedIn, 18 Oct 2026.

> ⚠️ **Honest warning:** Stripe interviews are **among the hardest in the industry**. Don't apply without 200+ LeetCode (75+ Medium/Hard) + 1 production-grade full-stack project + 1 system design project.

### 🟧 Job 4: Microsoft — Data Science Intern (JD 6517) 🔥 HIGHLIGHTED

**Snapshot:**
| Field | Value |
|---|---|
| Stipend | **₹1,25,000/month (₹1.25 Lakh/mo)** 🔥 — one of the highest in India |
| Location | Bengaluru, Hyderabad, Pune, Gurgaon (multi-location) |
| Batch | **2029 / 2028** (rare — 1st-year B.Tech eligible) |
| Type | Internship + FTE (PPO path) |
| JD ID | **6517** (thejobcompany.co.in) |
| Apply | [https://thejobcompany.co.in/frontend/job_details?job_id=6517](https://thejobcompany.co.in/frontend/job_details?job_id=6517) |
| Updated | 18 October 2026 |

**What You'll Do:**
- **Use machine learning, statistics, and experiments** to build and improve Microsoft products
- **Collaborate with stakeholders** — product, engineering, business — to formulate approaches
- **Combine engineering with analytical skills** — make customer experiences better
- **Innovate daily** with novel algorithms and tools
- **Make business impact** — your work affects millions of Microsoft customers

**Responsibilities (from JD):**
1. Formulate approaches to solve problems using well-defined algorithms and data sources
2. Incorporate understanding of product functionality and customer perspective
3. Use data exploration techniques to discover new questions or opportunities
4. Interpret results of analysis, validate approach, monitor and iterate to improve
5. Engage with stakeholders to produce clear, compelling, actionable insights
6. Participate in peer review process and act on feedback

**Must-Have Skills:**
- Currently pursuing Bachelor's or Master's in **Data Science, Mathematics, Statistics, Econometrics, Economics, Operations Research, Computer Science, or related field**
- **At least one additional quarter/semester of school remaining** after internship
- Strong fundamentals in statistics, probability, linear algebra
- Python for data science (pandas, scikit-learn, numpy, matplotlib)
- SQL fluency
- ML basics (regression, classification, clustering, evaluation metrics)

**Eligible Batches:**

| **2028** | ✅ Strong | Prefinal-year, will have 1+ year remaining after internship |
| **2029** | ✅ Strong | 1st-year, plenty of time remaining — **rare Tier-1 opportunity for 1st years** |

**Eligible Branches / Disciplines:**
| Discipline | Fit | Why |
|---|---|---|
| **Computer Science (CS / CSE)** | ✅ Strong | Listed in JD |

## 📧 Cold Email / DM Strategy

For each of the 4 companies, use the same template structure but customize:

1. **Subject line:** "B.Tech [Branch] [Year] — Interested in [Role] at [Company] | [Key Skill]"
2. **First paragraph:** Quick snapshot (batch, CGPA, DSA stats, projects)
3. **Second paragraph:** Why this company specifically (not generic)
4. **Third paragraph:** Specific ask (15-min call or DM response)
5. **Signature:** LinkedIn + GitHub + Phone

**Recruiter finding methods (for each company):**
1. LinkedIn search: "[Company] recruiter [City]"
2. Company's careers page → "Connect with Recruiter" link
3. Alumni network: Search "[Company]" + "[Your College]"
4. Cold email to Engineering Manager: Search "Engineering Manager [Company] [City]"
