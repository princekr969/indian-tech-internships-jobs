## 🎯 What This Role Is About

**Harmonic (NASDAQ: HLIT)** is the **global leader in virtualized broadband solutions** — the company that pioneered the industry's first **virtualized broadband platform (CableOS)** and now powers **multi-gigabit broadband for service providers worldwide** (Comcast, Charter, Vodafone, BT, Liberty Global, etc.).

As an **Associate SW Development Engineer** on the **Broadband Devices Team**, the work is **firmware / embedded systems engineering for the network devices** that sit at the edge of the broadband network — Remote PHY Devices (RPDs), DOCSIS 4.0 nodes, fiber access equipment. The role is **NOT a web/frontend/backend cloud role** — it is **systems-level C/C++ engineering for telecom hardware**.

```
┌────────────────────────────────────────────────────────────────────┐
│              HARMONIC BANGALORE — BROADBAND DEVICES                │
├────────────────────────────────────────────────────────────────────┤
│  Daily work:                                                       │
│   • Read JIRA / bug ticket from QA or customer support             │
│   • Reproduce issue on real RPD / cable-modem hardware             │
│   • Debug cross-layer: L2/L3 → Linux kernel → app → hardware       │
│   • Write C/C++ patch + Python/Perl/Bash test scripts              │
│   • Submit change → review with senior engineer → merge to main    │
│   • Field-test on lab equipment + customer network                 │
│                                                                    │
│  Stack:                                                            │
│   C / C++ (primary)  →  Embedded Linux  →  SONiC / SAI             │
│   Python / Bash / Perl (test + tooling)                            │
│   Layer 2/3 networking (DOCSIS, R-PHY, Ethernet, IP)               │
│   Linux kernel / user-space / drivers                              │
│   Docker / containers (advantage)                                  │
└────────────────────────────────────────────────────────────────────┘
```

> **Honest fit note:** This is a **genuine embedded / systems role**, not a Java/React web role. Candidates with **strong C/C++ fundamentals, comfort with Linux, and curiosity about networking protocols** will thrive. Candidates whose only experience is web development (React/Node/Django) will struggle — the on-site debugging involves real hardware, kernel logs, and packet captures.

## ✅ What You'll Do (Responsibilities)

1. **Develop software features for Embedded Systems** — write new C/C++ code for Harmonic's broadband network devices.
2. **Debug and resolve complex cross-layer system issues** reported by QA and customers — perform root cause analysis across hardware, firmware, OS, and application layers.
3. **Implement long-term corrective and preventive solutions** — not just hotfixes; systemic fixes that prevent recurrence.
4. **Collaborate with hardware teams** — read schematics, datasheets, and PCB layouts to understand physical-layer behaviour.
5. **Troubleshoot and debug network devices and products** — use Wireshark, tcpdump, gdb, strace, perf, ftrace.
6. **Build and maintain test infrastructure** — Perl/Python/Bash scripts for regression, soak, and load testing.
7. **Participate in Agile/Scrum ceremonies** — sprint planning, estimation, retros, daily standups.
8. **Work in a hybrid setup** — 3-4 days per week in the Bangalore office for lab work; 1-2 days WFH.
