## What This Role Is About

> *From the JD: "We have an exciting opportunity for a passionate Web Accessibility Engineer to join our CoE team and grow their expertise in accessibility consulting."*

This role sits inside **Apple's IS&T Accessibility Center of Excellence (CoE)** — a global team that helps all of Apple make websites, internal systems, and services work for **everyone** (including users with disabilities). The CoE is the central authority for embedding accessibility into customer-facing and employee-facing digital products across Apple's IS&T EMEIA region.

The intern/engineer performs **accessibility evaluations of web applications**, documents findings, contributes actionable code fixes (HTML/CSS/JS remediation), and collaborates with product, design, and engineering teams across the project lifecycle. This is a **niche, high-leverage role** — most freshers don't even know accessibility engineering exists as a career.

---

## Key Responsibilities

- Run **accessibility evaluations** of web applications using established WCAG-based testing methodologies
- Document findings clearly and contribute actionable remediation recommendations under senior guidance
- Identify and contribute **accessible code fixes** using HTML, CSS, and JavaScript
- Test interfaces with assistive technologies (VoiceOver, JAWS, NVDA)
- Collaborate cross-functionally with product, design, and engineering throughout the project lifecycle
- Support accessibility reviews so **inclusive experiences are built in from the ground up**
- Contribute to the team's **accessibility training materials, tooling, and standards** as you grow in the role

## Selection Process (Apple-Standard Pattern)

```
Resume review
  - Apple recruiters filter for explicit keywords: WCAG, WAI-ARIA, VoiceOver, JAWS, NVDA, screen reader
  - College tier + relevant coursework + accessibility portfolio all matter
     ↓
Recruiter phone call (30 min)
  - Background, motivation, basic fit
  - Walk through resume + accessibility projects
     ↓
Technical phone / video screen (60 min)
  - HTML, CSS, JavaScript fundamentals
  - DOM manipulation questions
  - Accessible markup patterns (semantic HTML, ARIA roles, keyboard navigation)
  - Live screen-reader walkthrough
     ↓
Onsite / final interview loop (3-4 rounds, full day or split)
  - Deep technical round (HTML/CSS/JS, accessibility patterns, debugging)
  - Cross-functional round (working with product / design / engineering)
  - Behavioral round (Apple's "Googliness"-style culture fit)
     ↓
Offer
```

> **Verify:** Apple's exact interview pipeline may vary by role + team. Plan for 3–4 rounds with a strong emphasis on **front-end fundamentals + accessibility depth**.
