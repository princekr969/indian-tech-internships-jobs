## ✅ Eligibility & Selection

### Eligibility
- 🎓 **2027 Bachelor's or Master's graduate** in CS / IT / related
- 📅 **Strong DSA + system design** fundamentals
- 💻 **1+ project** showing distributed systems, cloud, or AI/ML experience
- 🌍 **No prior full-time experience** (internships OK)
- 📊 **7.0+ CGPA** typically (varies by team)

### Selection Process

| Stage | Format | What It Tests |
|---|---|---|
| **1. Resume screen** | ATS keyword match | CGPA + projects + skills |
| **2. Online Assessment** | Codility / HackerRank | 2-3 DSA problems (medium) |
| **3. Virtual interview loop** | 3 rounds (Teams + CoderPad) | DSA + projects + system design |
| **4. As-Appropriate (AA) round** | Final interview | Behavioral + culture fit |
| **5. Offer** | Via recruiting team | — |

**Total timeline:** 6-10 weeks. **Cooldown:** 6 months if rejected.
