## 🎯 What This Role Is About

Mastercard's Pune Engineering org builds the **payments and risk platforms that move trillions of dollars across 200+ countries**. As a **Software Engineer I**, the work is **hands-on production code** in **Java 17 + React JS** on top of **Oracle / PostgreSQL** databases — the same stack that powers **tokenization, fraud detection, and the Mastercard Send / Cross-Border rails**.

The role is **NOT a research / data-science / ML position** — it is a **classic product-engineering seat** with:

- 70 % backend (Java 17, Spring-style services, REST APIs, Oracle/PostgreSQL)
- 20 % frontend (React JS)
- 10 % cross-cutting (secure code, code-quality tooling, design patterns, CI/CD)

The JD says "**understands**" instead of "masters" for almost every skill → this is a **fresh-grad / 0-2 yrs experience** profile, not a senior role.

## ✅ What You'll Do (Responsibilities)

1. **Analyze, design, develop, and deliver** software solutions for payments / risk / identity products.
2. **Define requirements** for new applications and customizations — adhere to Mastercard SDLC standards.
3. **Write secure, well-tested Java 17 + React JS code** in delivery tasks (code, test, deploy).
4. **Take guidance from senior engineers** while owning assigned work end-to-end.
5. **Proactively request code reviews** and apply feedback — participate in Guild / Engineering community initiatives.
6. **Understand end-to-end logical architecture** of systems in your ownership area — not just the file you changed.
7. **Provide improvement feedback** on existing processes, tooling, and codebase.
8. **Apply Mastercard technology policies** (security, data handling, change management) in everyday work.
9. **Participate in Agile ceremonies** — elaboration, sprint planning, estimation, retros (SAFe / Scrum / Kanban — pick your team's flavor).

### Difficulty Tier

| Round | Difficulty (1-5) | Comparable To |

## 📝 How to Apply

### Step 1: Prepare Resume (Before Clicking Apply)

**Mastercard-specific resume tweaks:**

1. **Header:** Name | Phone | Email | LinkedIn | GitHub | Portfolio (no photo, no DOB, no father's name).
2. **Education:** B.Tech CSE, XYZ University, 2022-2026, CGPA: 8.4/10.
3. **Projects (2-3 max):** Each project should have:
   - One-line problem statement
   - Tech stack (Java 17, Spring Boot 3, React JS, PostgreSQL)
   - 2-3 bullet points: what YOU built, not what the team built
   - GitHub link + live demo link (if hosted)
4. **Experience / Internships:** Use STAR format (Situation, Task, Action, Result) with **measurable outcomes** (e.g., "Reduced API latency by 35 %" or "Shipped 4 features to 50K users").
5. **Skills section:** Group by category — Languages, Frameworks, Databases, Tools, Cloud. Mention Java 17 explicitly (not just "Java").
6. **Achievements:** JEE / GATE rank, ICPC / CodeChef rating, hackathon wins, open-source contributions.
7. **Length:** 1 page for freshers, 2 pages for 1+ yr experience.
8. **ATS optimization:** Mirror keywords from the JD — Java 17, React JS, Oracle, PostgreSQL, REST APIs, CI/CD, Gitflow, design patterns, Sonar, Zally, Checkmarx.

### Step 2: Apply on Careers Portal

1. Go to [https://careers.mastercard.com/us/en/job/MASRUSR292435EXTERNALENUS/Software-Engineer-I](https://careers.mastercard.com/us/en/job/MASRUSR292435EXTERNALENUS/Software-Engineer-I).
2. Click **"Apply Now"**.
3. Sign in via **LinkedIn** (fastest) or create an account.
4. Upload resume (PDF preferred, ≤ 2 MB).
5. Fill in demographic questions (US-style EEO form — leave blank if not applicable).
6. Add cover letter (optional but recommended for SWE I — see template below).
7. Submit. You'll get a **confirmation email** with the application ID within 5 minutes.
