## What This Role Is About

> *From the JD: "Onehouse is a mission-driven company dedicated to freeing data from data platform lock-in. We deliver the industry's most interoperable data lakehouse through a cloud-native managed service built on Apache Hudi."*

Onehouse is building a **fully managed, self-optimizing data lakehouse** on top of **Apache Hudi** (an open-source data lake framework used at scale by Uber, Amazon, ByteDance). This role sits in the **Data Infrastructure team** — the engineers who "live and breathe databases, building cornerstone infrastructure by working under Hudi's hood to solve incredibly complex optimization and systems problems."

**The work you do:**
- Design new concurrency control and transactional capabilities for competing writers
- Design indexing schemes optimized for incremental data processing and analytical query performance
- Build systems that scale and streamline metadata/data access across query/compute engines
- Solve hard optimization problems to improve efficiency (more performance, less cost) of distributed data processing over Kubernetes
- Collaborate to implement and deploy optimized solutions in production
