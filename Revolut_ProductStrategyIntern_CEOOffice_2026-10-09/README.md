## ✅ Eligibility & Selection

### Eligibility
- 🎓 **2027 Bachelor's or Master's graduate** in CS / IT / Business / Economics
- 📅 **Strong product thinking + analytical skills + SQL/Excel/Tableau**
- 💻 **1+ project with product / strategy / analytics**
- 🌍 **Comfort with remote work + global team collaboration**
- 📊 **Strong academic record** (7.5+ CGPA, no backlogs)

### Selection Process

| Stage | Format | What It Tests |
|---|---|---|
| **1. Application** | Portal | Resume + cover letter + projects |
| **2. Online Assessment** | HackerRank / custom | Analytical + case study |
| **3. Hiring Manager Screen** | Virtual | Product sense + motivation |
| **4. Case Study Round** | Take-home (3-5 days) | Real Revolut product/strategy problem |
| **5. Onsite (3-4 rounds)** | Virtual | Product strategy + analytical + behavioral |
| **6. CEO Office Final Round** | Virtual | Strategic thinking + culture fit |
| **7. Offer** | Via recruiting | PPO based on intern performance |

**Total timeline:** 6-8 weeks.
