## ✅ Eligibility & Selection

### Eligibility
- 🎓 **2027 Bachelor's graduate** in CS / IT / related
- 📅 **Frontend: React/Next.js + TypeScript + Tailwind + state management**
- 💻 **1+ project with modern frontend stack**
- 🌍 **Interest in cybersecurity a plus**
- 📊 **6.0+ CGPA** typical

### Selection Process

| Stage | Format | What It Tests |
|---|---|---|
| **1. Application** | Portal | Resume + projects + GitHub |
| **2. Online Assessment** | HackerRank | DSA + frontend (React/JS) |
| **3. Technical Interview (1-2 rounds)** | Virtual | Frontend + DSA + projects |
| **4. HR Discussion** | Virtual | Role expectations + stipend |
| **5. Offer** | Via recruiting | PPO based on intern performance |

**Total timeline:** 3-5 weeks.
