## 🎯 How to Use This Library

### For Students (Reading)

1. **Browse by tier** — start with Tier 1 if you want highest-payout roles
2. **Check the batch eligibility table** in each README before applying
3. **Read the "Expected Start & End Dates"** — confirm timeline alignment with your graduation
4. **Read the "Important Notes" section** — flags batch restrictions + scam warnings
5. **Copy the WhatsApp snippet** for any role you want to share with your group
6. **Use the cold-email template** as a starting point (customize per role)

### For Sharing on WhatsApp Groups

1. Open the role's README on GitHub
2. Scroll to the **"WhatsApp-Ready Shareable Snippet"** section
3. Copy the snippet block
4. Paste directly into your WhatsApp group
5. Optionally include the **D: drive path** for friends who want the full file

### For Contributors (Adding New Roles)

Each new entry should:
1. Be created in a **new folder** named `<Company>_<Role>_<Location>_<YYYY-MM-DD>/`
2. Contain a single `README.md` following the standard template
3. Include all 9 standard sections + Expected Start/End Dates
4. Use generic, impersonal language (no "you" / "for you")
5. Avoid including any scam recruitment posts (verify the company first)

## ⚠️ Important Disclaimer

This repository is a **personal curation of public job postings** — not an official jobs portal.

- 🚫 **No recruiter fees, ever** — every entry is free to apply
- 🚫 **No paid promotions** — entries are not sponsored
- ✅ **All postings are publicly accessible** on LinkedIn, careers portals, or Unstop/Devpost
- ⚠️ **Always verify on the official careers page** before applying — some postings may have closed, moved, or changed requirements
- ⚠️ **Beware of scam recruitment posts** that mimic real company names — always apply through `careers.<company>.com` or verified LinkedIn posts
