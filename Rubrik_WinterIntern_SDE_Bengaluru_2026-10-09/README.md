## ✅ Eligibility & Selection

### Eligibility
- 🎓 **2027 Bachelor's or Master's graduate** in CS / IT / related
- 📅 **DSA + Go/Java/Python + distributed systems + cloud (AWS/Azure/GCP)**
- 💻 **1+ project with distributed systems / data engineering**
- 🌍 **Interest in cybersecurity / data management a plus**
- 📊 **7.0+ CGPA** typical

### Selection Process

| Stage | Format | What It Tests |
|---|---|---|
| **1. Application** | Portal | Resume + projects + GitHub |
| **2. Online Assessment** | HackerRank | DSA + coding (2-3 problems) |
| **3. Technical Interview (2-3 rounds)** | Virtual | DSA + system design + projects |
| **4. Hiring Manager Round** | Virtual | Behavioral + role fit |
| **5. Offer** | Via recruiting | PPO based on intern performance |

**Total timeline:** 4-6 weeks.
