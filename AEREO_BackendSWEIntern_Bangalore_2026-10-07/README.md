## Selection Process — Unique Format

> 💡 AEREO uses a **practical engineering task** instead of pure resume review. This is unusual and gives strong candidates a real edge.

| Stage | Format | What It Tests |
|---|---|---|
| **1. Practical Engineering Assignment** | Build a small solution, publish on **GitHub**, demonstrate approach | Real problem-solving + coding skill |
| **2. Technical Interview(s)** | Discussion of assignment + DSA + system design basics | How you think, edge cases, code quality |
| **3. HR Discussion** | Culture fit, motivation, logistics | Stakeholder management |

> 🎯 **The GitHub-published solution is the differentiator.** Even mediocre solutions with clean code + good documentation can outperform polished resumes.

## Apply Tip

- 📂 Resume MUST show **Python, Django/FastAPI, REST APIs, PostgreSQL/MySQL, microservices**
- 🛠️ Show **GitHub repos** with at least 1-2 production-grade backend projects (APIs, auth, microservice)
- 🐛 Discuss **debugging stories** + system optimization examples

- 🌐 Highlight any **GIS / geospatial** curiosity (even academic)
