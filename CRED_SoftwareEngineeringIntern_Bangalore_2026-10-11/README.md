## What This Role Is About

> *From the JD: "here's what's in store for you at CRED once you join as a backend engineering intern — in 2026, that means building with AI as a core part of how you work, not as an afterthought."*

This is CRED's **AI-native SWE intern** track — the role explicitly calls out using coding agents (Copilot, Cursor, Claude Code, ChatGPT) and LLM tooling as part of the default engineering workflow, while still owning engineering judgment.

---

## Key Responsibilities

- Solve real production problems with mentorship from senior engineers
- Design, build, test, and ship features and services end-to-end
- Apply an **AI-native engineering workflow by default** (coding agents + LLM tooling)
- Own the reliability and outcomes of the areas under your responsibility
- Write code that's correct under edge cases — not just code that "looks right" to an autocomplete
- Apply real SWE fundamentals (testing, system design basics, data structures, APIs) as the backbone under any AI-assisted workflow

```
Application form submission (CodeChef Jobboard)
     ↓
Online Assessment
   - DSA (medium-hard, 2-3 questions)
   - CS fundamentals (OS, CN, DBMS, OOP)
     ↓
Technical Interview Round 1 (60 min)
   - 1-2 DSA problems
   - System design / fundamentals
     ↓
Technical Interview Round 2 (60 min)
   - Project deep-dive
   - AI-native engineering discussion
   - Architecture / LLD
     ↓
HR / Hiring Manager Round (30-45 min)
   - Behavioral, why CRED, AI workflow philosophy
     ↓
Offer
```

> **Verify:** CRED is known for a rigorous, multi-round technical interview. Their interns typically get strong PPO conversion to FTE at ₹22-30+ LPA.
