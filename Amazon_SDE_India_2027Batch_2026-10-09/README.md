## ✅ Eligibility & Selection

### Eligibility
- 🎓 **2027 Bachelor's or Master's graduate** in CS / IT / related
- 📅 **DSA + Java/Python/C++ + system design + OS fundamentals**
- 💻 **1+ project with distributed systems / microservices / cloud**
- 🌍 **No prior full-time experience**
- 📊 **6.5+ CGPA** typical (varies by team)

### Selection Process

| Stage | Format | What It Tests |
|---|---|---|
| **1. Application** | Portal or on-campus | Resume + CGPA + projects |
| **2. Online Assessment (1-2 rounds)** | HackerEarth / HackerRank | DSA + coding (2-3 problems) |
| **3. Technical Interview (2-3 rounds)** | Virtual / on-campus | DSA + projects + system design + LP |
| **4. Bar Raiser Round** | Virtual | Amazon's 14 Leadership Principles deep-dive |
| **5. Offer** | Via T&P or portal | — |

**Total timeline:** 4-8 weeks.

### Amazon's 14 Leadership Principles (Critical for Final Round)

1. Customer Obsession
2. Ownership
3. Are Right, A Lot
4. Learn and Be Curious
5. Hire and Develop the Best
6. Insist on the Highest Standards
7. Think Big
8. Bias for Action
9. Frugality
10. Earn Trust
11. Dive Deep
12. Have Backbone; Disagree and Commit
13. Deliver Results
14. Strive to be Earth's Best Employer

> 📚 **Prepare 1-2 stories per LP** using the **STAR method** (Situation, Task, Action, Result).
