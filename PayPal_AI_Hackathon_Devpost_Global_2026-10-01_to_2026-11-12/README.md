## 🔍 How to Get Started (Step-by-Step)

### Day 1 (Oct 5 or whenever you start)
- [ ] Register at https://paypalaihackathon.devpost.com/
- [ ] Create **PayPal Developer Account** at https://developer.paypal.com/
- [ ] Get your **sandbox credentials**
- [ ] **Brainstorm** project ideas (use WhatsApp group, Discord, etc.)

### Day 2-3 (Setup)
- [ ] Set up **GitHub repo** with open-source license (MIT recommended)
- [ ] Sign up for free tier on **sponsor platforms** you want to use:
  - Postman (API testing)
  - Render (hosting)
  - Elastic (search)
  - AG Grid (data tables)
  - APIMatic (API generation)

### Week 1-2 (Build MVP)
- [ ] Start with **PayPal sandbox integration** (most important)
- [ ] Add **AI feature** (OpenAI/Claude API is easiest)
- [ ] Make it **work end-to-end** (even if rough)
- [ ] Document progress on GitHub

### Week 3-4 (Iterate)
- [ ] Polish UI/UX
- [ ] Add error handling
- [ ] Test edge cases
- [ ] Get feedback from 1-2 people

### Week 5-6 (Demo Video + Submission)
- [ ] Record **< 3 min demo video** (script first!)
- [ ] Upload to **YouTube (public)**
- [ ] Write **clear text description** (problem, solution, tech stack)
- [ ] **Submit** before Nov 12, 12 PM PST!
