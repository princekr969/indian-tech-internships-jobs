## 🎯 What This Role Is About

**Electronic Arts** is one of the world's largest game publishers — **FIFA / EA Sports FC, Apex Legends, The Sims, Battlefield, Star Wars games, Mass Effect, Dead Space**. Roughly **700+ million registered players**, ~$7.4 B annual revenue, ~13,700 employees.

But this role is **not** game development. This is **EADP — EA Digital Platform**, the organization that builds the **shared infrastructure that every EA studio depends on**: cross-platform services, account/auth systems, cloud-native platforms, and the tooling that lets game teams ship on PC, console, and mobile simultaneously.

As a **JAVA SE Intern** on **CT — Infrastructure & Platform**, you will work on **large-scale distributed microservices** in Java that power EA's global gaming platform. This is **backend / platform engineering**, not gameplay engineering.

```
┌────────────────────────────────────────────────────────────────────┐
│         EA DIGITAL PLATFORM (EADP) — HYDERABAD — JAVA INTERN      │
├────────────────────────────────────────────────────────────────────┤
│  Daily work:                                                       │
│   • Pick up JIRA ticket from PM / senior engineer                  │
│   • Prototype + build large-scale distributed services (Java)      │
│   • Build & deploy new microservices; extend existing ones         │
│   • Write unit + integration tests; raise automated coverage       │
│   • Profile cloud-native apps for performance & scale problems    │
│   • Add observability: metrics, traces, telemetry on new features │
│   • Stand-up: report progress + blockers                          │
│   • Code review with senior engineers + peers                     │
│                                                                    │
│  Stack:                                                            │
│   Java (core) / Scala (optional)                                  │
│   Microservices  →  Docker  →  Kubernetes (cloud native)           │
│   SQL + NoSQL databases                                            │
│   CI/CD pipelines  →  Git  →  observability stack                 │
└────────────────────────────────────────────────────────────────────┘
```

> **Honest fit note:** This is a **backend platform engineering** role. It is **NOT** C++ game development, NOT Unity/Unreal, NOT graphics. Candidates who want to build games should not apply here. Candidates who want to build **the infrastructure that games run on** should.

## ✅ What You'll Do (Official Responsibilities)

1. **Work with Product Managers, senior engineers and peers** to understand requirements, prototype & build large-scale distributed applications.
2. **Build & deploy new microservices** and enhance the feature set of existing microservices.
3. **Maintain a keen eye on code quality, testability, maintainability & automated test coverage.**
4. **Analyze and troubleshoot cloud-native applications** relating to performance & scale.
5. **Implement observability, metrics, traces and telemetry** for features to gauge success.
6. **Prototype new technology** that fits use cases / problems and validate against success criteria.
7. **Communicate and coordinate with teams across various geographies** (EA is globally distributed).
8. **Communicate progress & issues in daily stand-ups.**

- **Foundational infrastructure role** — your code underpins every EA game service.

- **Microservices + observability is demanding for a fresher.** The bar is higher than a typical "learning internship" — they want someone who can ship to prod.

```

│  Stage 4: TECHNICAL INTERVIEW — ROUND 2  (60 mins)                 │
│  └- System design / architecture (low-level)                       │
│  └─ Microservices, caching, database design, latency trade-offs    │
│  └- "Tell me about a project you shipped" + observability thinking │
│                                                                    │
│  Stage 5: HR / CULTURE FIT  (30-45 mins)                           │
│  └- Cross-timezone collaboration scenarios                         │
│  └- "Why EA? Why games? Why platform engineering?"                 │
│  └- Availability, duration, stipend confirmation                    │
│                                                                    │

│  └- Stipend, start date, team assignment, PPO discussion            │
└────────────────────────────────────────────────────────────────────┘
```

### Difficulty Tier

| Round | Difficulty (1-5) | Comparable To |
|---|---|---|
| Online Assessment | 3 | Java DSA screening, Medium LeetCode |
| Technical Round 1 | 3 | Product-company SDE level; DSA + OOP + patterns |
| Technical Round 2 | 4 | Low-level system design + microservices architecture |
| HR / Culture | 2 | STAR storytelling + EA motivation |

> **Reality check:** EA is **below FAANG difficulty** but **above typical service-company difficulty**. The distinguishing factor is the **design patterns + observability + cloud-native** depth — many freshers can solve DSA but cannot discuss distributed systems trade-offs. Prepare for both.
