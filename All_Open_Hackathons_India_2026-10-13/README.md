# Section 9 — Pre-Application Checklist

```
[ ] Pick 2-3 hackathons that match your interests + skills
[ ] Form a team (2-4 members usually) — diverse skills (frontend/backend/AI/UI)
[ ] Verify eligibility (batch, branch, location constraints)
[ ] Check team size rules (some require exactly N members)
[ ] Read the problem statement themes (if pre-announced)
[ ] Set up GitHub repos (one per hackathon for clean delivery)
[ ] Cold email referrals/judges if listed as optional
[ ] Submit application BEFORE deadline (rolling sites go fast)
[ ] Calendar all deadlines (set reminders 1 week + 1 day before)
[ ] Prepare your team's dev environment (Git, VSCode, frameworks, AI tools)
```
