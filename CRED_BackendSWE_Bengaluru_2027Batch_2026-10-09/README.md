## ✅ Eligibility & Selection

### Eligibility
- 🎓 **2027 Bachelor's or Master's graduate** in CS / IT / related
- 📅 **Strong DSA + system design fundamentals**
- 💻 **Java/Python/Go proficiency + Git + REST APIs**
- 🤖 **Comfort with AI tools** (Copilot, Cursor, Claude Code)
- 🌍 **Prior internship is a plus, not mandatory**
- 📊 **60%+ / 6.0+ CGPA** (relaxable for strong projects)

### Selection Process

| Stage | Format | What It Tests |
|---|---|---|
| **1. Application & Resume Screening** | CodeChef / careers | Fundamentals + projects + role fit |
| **2. Online Assessment** | HackerRank | Aptitude + DSA + System design basics |
| **3. Technical Interview (1-2 rounds)** | Virtual | Projects + practical scenarios |
| **4. HR Discussion** | Virtual | Role expectations + stipend + start date |
| **5. Offer** | Via recruiting | PPO based on intern performance |

**Total timeline:** 4-6 weeks.
