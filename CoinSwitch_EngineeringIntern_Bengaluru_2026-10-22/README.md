## 🎯 What This Role Is About

**CoinSwitch** is **India's largest crypto investing app** (130K+ LinkedIn followers, ~417 employees on LinkedIn, Bangalore HQ). It sits under **PeepalCo** — a canopy of wealth-tech brands serving India with its mission *"Making Money Equal for All."* The other major PeepalCo brands are **Lemonn** (trading), **Wio**, and others.

As an **Engineering Intern** at CoinSwitch, you work on the **production crypto exchange infrastructure** — the backend services that match buy/sell orders, the wallet/ledger system that tracks crypto balances, the KYC/onboarding flow, and the customer-facing app surfaces where people actually buy crypto with INR.

This is **not** a "learn React" internship. It's a **high-velocity fintech/crypto product** where code touches real money and real users from day one.

## ✅ What You'll Do (from the JD)

1. **Build cutting-edge, scalable systems** by writing simple, efficient and performant code — and **push your design** for review, not just the diff.
2. **Work closely with the engineering team** to develop and maintain **integrations of best practices** within the engineering group.
3. **Monitor system uptime and errors** to drive the product toward a **high-performing and reliable** state.
4. **Take ownership** of code quality, elegance, and robust infrastructure.
5. **Translate requirements and mockups into fully functioning features** using frontend technologies.

### Hidden Signals From the JD (Worth Noting)

| Signal in JD | What it really means |
|---|---|
| "**push your design**" | They want you to defend design decisions in review, not just hand over code. Prep to justify your approach. |
| "**monitor system uptime and errors**" | You'll touch observability — expect on-call-adjacent exposure and alert-driven work. |
| "**integrations of best practices**" | Less feature-building, more platform/tooling work (CI, linting, test infra). Good for resume depth. |
| "**graduating in 2027**" | Hard batch filter. 2026/2028 grads will likely be filtered out at resume screen. |
| "**hacker mindset**" + "**love exploring new technologies**" | They self-describe as engineering-culture-driven. Mention side projects / open source / weekend builds in resume. |
| Listed languages: **Python, Golang/Java, React Native, React JS** | Python **or** Go **or** Java is enough. React Native + React JS covers frontend. No need for all five. |

### Difficulty Tier

| Round | Difficulty (1-5) | Comparable To |
|---|---|---|
| Online Coding | 2-3 | Standard DSA screening, Medium LeetCode |
| Technical Round 1 | 3 | Service-company SDE level; DSA + project depth |
| Technical Round 2 | 3 | System design basics + debugging scenario |
| HR / Culture | 2 | STAR storytelling + crypto motivation |

> **Reality check:** CoinSwitch is **not** a FAANG-level interview — DSA is the main gate, and they're honest that "experience in a specific tech stack doesn't matter." What they *do* care about is **engineering judgment** and **debugging instinct**, because exchange bugs are expensive.
