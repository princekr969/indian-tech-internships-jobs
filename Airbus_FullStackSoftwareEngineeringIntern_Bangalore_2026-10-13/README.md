## What This Role Is About

> *From the JD: "An internship opportunity titled « Software Engineering Intern – Full Stack (ReactJS / Python) » has just opened at Airbus India located in Bangalore. You will join the 'ERP CoE Manufacturing Engineering – IIDEM' department."*

This is a **6-month, full-time internship** in Airbus India's **ERP Center of Excellence (CoE) for Manufacturing Engineering — IIDEM** team. IIDEM is Airbus's internal "Industrial Digital Engineering & Manufacturing" function — they build the digital backbone that supports Airbus's manufacturing, MRO (maintenance, repair, overhaul), and engineering operations across the company.

**The work you do:**
- Develop, test, and maintain modern, responsive **web UIs using ReactJS** (front-end focus)
- Assist in design + integration of **backend services and scripts in Python / TypeScript / Node.js** (back-end collaboration)
- Collaborate with cross-functional development teams to integrate **RESTful APIs**
- Contribute to full-stack feature delivery in production-grade enterprise applications
- Participate in **Agile/Scrum**, code reviews, version control (Git), and software engineering best practices

> **Reality check:** "ERP CoE" = you'll be working on internal tools / dashboards / data applications that Airbus's manufacturing and engineering teams use day-to-day. This is **enterprise software** (not consumer products), but the tech stack is modern (React, Python/TS, Node) and the work is real production code — not throwaway internship tasks.
