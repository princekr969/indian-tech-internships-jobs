## ✅ Eligibility & Selection

### Eligibility
- 🎓 **2027 Bachelor's or Master's graduate** in CS / IT / related
- 📅 **DSA + Java/Python/Node + SQL + cloud**
- 💻 **1+ project with payment / fintech / distributed systems**
- 🌍 **No prior full-time experience**
- 📊 **7.0+ CGPA** typical, varies

### Selection Process

| Stage | Format | What It Tests |
|---|---|---|
| **1. Application** | Portal or on-campus | Resume + CGPA + projects |
| **2. Online Assessment** | HackerRank / HackerEarth | DSA + coding (2-3 problems) |
| **3. Technical Interview (2 rounds)** | Virtual | DSA + projects + system design |
| **4. Hiring Manager Round** | Virtual | Behavioral + role fit |
| **5. Offer** | Via recruiter | — |

**Total timeline:** 4-6 weeks.
