## About CRED

- Premium fintech founded by **Kunal Shah** (ex-FreeCharge)
- HQ: **Bengaluru**, MSR North Tower, Manayata Tech Park
- Members-only credit card bill payment + rewards platform
- Products: CRED Pay, CRED Cash, CRED Mint (lending), CRED Store, CRED Garage
- Funded by **DST Global, Sequoia, GIC, Falcon Edge, Tiger Global**
- ~15M+ verified members, ~$1B+ processed in rewards
- Engineering culture: **design-first, very high bar, top-tier total comp**

## What You'll Work On (Backend Intern)

- ⚙️ Build backend services / APIs powering **credit card payments, rewards, lending**
- 🏦 Design and ship features for **CRED's money products**
- 🧩 Microservices using **Go + gRPC** or **Kotlin + gRPC** (or Node.js in some teams)
- 🗄️ Database design, query optimization, schema migrations
- 🤝 Code reviews with senior engineers, system design exposure
- 🚀 Real production code with measurable ownership

## Tech Stack

- **Core backend:** **Go · Kotlin** · gRPC microservices
- **Also hiring:** **Java · Python · Node.js** (team-dependent)
- **Frontend collab:** React (basic full-stack understanding helps)
- **Datastores:** PostgreSQL · MySQL · Redis · Kafka
- **Infra:** Docker · Kubernetes · AWS · GCP
- **AI tooling:** Bonus if you use **GitHub Copilot / ChatGPT / Claude** for dev velocity
- **Practices:** Testing, edge-case identification, API design, system design basics

## Requirements

- 🎓 **B.E. / B.Tech / BCA / MCA / B.Sc. (CS / IT / ECE)** — pursuing or completed
- 📅 **Graduation year: 2027 (preferred), 2026, 2025** also eligible
- 📊 **Min 60% / 6.0 CGPA** (relaxable for strong practical projects)
- 💻 Proficiency in **at least one programming language** (Java / Python / Go / Kotlin / Node.js)
- 🧠 Solid **DSA fundamentals** — arrays, trees, graphs, heaps, DP, recursion
- 📚 Understanding of **APIs, REST, testing, edge cases**
- 📈 Basic **system design** awareness (sorting, probability, combinatorics)
- 🤖 Bonus: use **AI tools** (Copilot, ChatGPT, Claude) to ship faster
- 🛡️ No prior industry experience required — freshers welcome
- 📂 **Strong practical projects** matter more than degree brand

## Selection Process

| Round | Focus | Tips |
|---|---|---|
| **1. Resume Screening** | Fundamentals + projects + role fit | Mention specific Go / Kotlin / Node.js + projects |
| **2. Online Assessment** | **DSA + aptitude + system design basics** | Practice LeetCode Mediums, sorting, recursion, DP |
| **3. Technical Interview(s)** | 1-2 rounds on projects, problem-solving, **DSA + System design basics + Git + REST APIs** | "How would you approach this?" — not definitions |
| **4. HR Discussion** | Stipend, start date, location, offer | Negotiate based on competing offers |

## Apply Tip

- 📝 Resume MUST show **Go / Kotlin / Java / Python** + at least **2 production-grade projects**
- 🎯 Use keywords: **gRPC, microservices, REST APIs, PostgreSQL, Docker, Kubernetes**
- 📌 **Mention specific tech**, not generic "backend development"
- 🚀 Highlight any **open-source contributions** or **live deployments**
- 🤖 Note any **AI tool usage** (Copilot, ChatGPT, Claude) for productivity
- 💼 **CRED never asks for money** at any stage — beware of scam recruitment
