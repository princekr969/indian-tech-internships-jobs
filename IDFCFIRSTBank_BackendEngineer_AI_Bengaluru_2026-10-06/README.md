## About IDFC FIRST Bank

- Merged entity (IDFC Bank + Capital First), listed since 2018
- Universal bank: retail, commercial, rural, corporate banking
- **AI Labs** is the in-house GenAI / banking-AI engineering unit
- Tech stack touches payments, fraud, credit decisioning, conversational banking
- ~20,000+ employees, Bengaluru is a major engineering hub

## What the AI Labs Team Builds

- 🧠 **GenAI-powered banking copilots** (chat + voice)
- 🤖 **Agentic AI workflows** for credit ops, collections, customer service
- 📊 **Risk + fraud ML models** in production
- 🔌 **Backend services** that power AI products (Python / Node.js / Go)
- 🚀 Internal AI enablement platform for the bank

## Tech Stack (Backend)

- **Languages:** Python · Node.js · Go
- **Frameworks:** FastAPI · Flask · Express
- **Async:** Asyncio · message queues (Kafka / RabbitMQ)
- **Datastores:** PostgreSQL · Redis · MongoDB
- **AI/ML:** LLM orchestration (LangChain / LlamaIndex), RAG, vector DBs
- **Infra:** Docker · Kubernetes · AWS · CI/CD
- **Frontend collab:** React (basic full-stack understanding needed)

## Requirements

- 🎓 **Bachelor's in CS / IT / BCA / B.Sc. (CS)** — or equivalent
- 💼 **2+ years** professional backend experience (per HireDoor; SWE-I track is fresher-internal)
- 💻 Strong in **Python, Node.js, or Go** + async programming
- 🏗️ Solid grasp of **scalable system design** + **backend architecture**
- 🎯 Familiarity with **design patterns** + best practices
- 🧪 Code review, debugging, unit testing mindset
- 🗃️ Database optimization (SQL + NoSQL)
- ☁️ Basic full-stack understanding (React a plus)
