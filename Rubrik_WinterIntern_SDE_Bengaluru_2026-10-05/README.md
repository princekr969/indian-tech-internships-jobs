## 🎓 Interview Prep Resources

- **Go (Golang):** Tour of Go, Go by Example, Effective Go
- **DSA:** LeetCode (target: 250+ problems, focus on trees, graphs, DP, heaps)
- **System Design:** High Level Design basics (load balancers, caching, DBs, microservices, distributed systems)
- **OS / DBs:** Process management, threading, indexing, transactions, ACID
- **Cloud:** AWS basics (EC2, S3, RDS), Docker, Kubernetes
- **Behavioral:** STAR method
- **Rubrik-specific:** Read about Rubrik's products (Polaris, Cloud Data Management, Ransomware Investigation)
