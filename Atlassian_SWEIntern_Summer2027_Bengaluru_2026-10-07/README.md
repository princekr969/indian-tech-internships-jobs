## Selection Process (5 Rounds)

| Stage | Format | What It Tests |
|---|---|---|
| **1. Apply** | Single-page PDF on atlassian.com/company/careers/earlycareers | OOP + DSA + open-source/hackathons |
| **2. HackerRank OA** | 90 min, 4 coding questions (LeetCode Easy–Medium) | DSA: graphs, DP, strings, arrays, design problems |
| **3. Recruiter Phone Screen** | 30 min | Background, motivation, logistics |
| **4. Technical "Craft" Interview** | 45-60 min | DSA problem + follow-ups; **code locally + screen share** |
| **5. Values Interview** | 45-60 min | Behavioral questions mapped to **Atlassian's 5 core values** (Open Company, No BS, Build with Heart + Balance, Don't #@!% the Customer, Play, as a Team) |
| **6. Hiring Committee Review** | Independent committee | Consensus-based decision |

**Total timeline:** 4–8 weeks from application to offer.

### Atlassian-Specific Interview Tips

- 🎯 **Atlassian is values-driven** — the **Values Interview is a non-negotiable gate**. Prepare 5-6 STAR stories covering success / achievements / setbacks / learning / collaboration.
- 💻 Coding interviews use **HackerRank** for OA, then your own laptop for the Craft round — set up IDE in advance.
- 🤖 **AI round**: Atlassian tests usage of tools like **Claude Code, Cursor, GitHub Copilot** — your comfort with AI-assisted engineering matters.
- 🧠 Atlassian assesses **problem-solving ability + thinking**, not language proficiency. **Choose any language** you're comfortable in (Java, Python, Go, TypeScript, C, C++, JavaScript).
- 🧩 **Systems design** (60 min): real-life engineering challenges, scaling systems, collaborative editing at scale

### Atlassian's 5 Core Values (memorize these!)

1. 🌟 **Open Company, No Bullshit** — Default to transparency, share information freely
2. 💚 **Build with Heart + Balance** — Bring passion AND sustainability
3. 🎯 **Don't #@!% the Customer** — Customer obsession, ship real value
4. 🤝 **Play, as a Team** — Collaboration > individual heroism
5. 🌍 **Be the Change You Seek** — Initiative over permission
