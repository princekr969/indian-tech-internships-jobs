## What This Role Is About

> *From the JD: "We are seeking a highly motivated LLM Research Intern with strong hands-on skills in PyTorch and a solid foundation in deep learning and NLP."*

This is a **pure R&D role** (not standard software maintenance). The intern collaborates with research scientists and engineers to build scalable, efficient, high-quality language technologies, particularly for **entertainment-domain translation and multilingual applications** (Sony's global business — think PlayStation, Sony Pictures, Crunchyroll, music streaming, etc.).

---

## Key Responsibilities

- Implement and experiment with **LLM-based models in PyTorch** — fine-tuning, evaluation, optimization
- Build and improve **multilingual pipelines** for Neural Machine Translation (NMT), NLP, and dialogue processing
- Support model training and inference optimization — memory-efficient training, batching strategies, decoding improvements
- Run experiments, benchmarks, and error analysis to improve model performance
- Help integrate models into prototype / production-ready systems under senior researcher guidance
- **Read and reproduce recent research papers** related to LLMs, and contribute to extending them for practical use cases

## Selection Process (Inferred Sony Research Pattern)

Sony Research India is known for a rigorous academic-style interview for research roles. The typical flow:

```
Resume + academic profile review
  - University tier, relevant coursework, published papers, GitHub ML portfolio
  - Project / paper work is heavily weighted
     ↓
Technical Screening (60 min)
  - Deep learning fundamentals (transformers, attention, backprop)
  - Python + PyTorch coding (implement a small model component or optimizer)
  - NLP / LLM theory (tokenization, fine-tuning strategies, evaluation metrics)
     ↓
Technical Interview Round 2 (60-90 min)
  - Research discussion (recent papers in LLMs, your prior work)
  - System design for a multilingual NLP pipeline
  - Live coding or take-home ML problem
     ↓
Researcher / Hiring Manager Round (45 min)
  - Research interests alignment
  - Why Sony, why research vs. industry
  - 6-month project proposal discussion
     ↓
Offer
```
