## What This Role Is About

> *From the JD: "We're hiring a Forward Deployed Engineer Intern to join the HR Technology team within People Success for a 12-week summer 2027 internship. This team builds the internal applications, integrations, and AI-powered workflows that help Coinbase employees move faster."*

You'll be on Coinbase's **HR Technology team** (inside the People Success org) — the team that builds **internal apps, integrations, and AI-powered workflows** that automate manual HR processes and improve employee experience. This is a real product engineering role with **end-to-end ownership**: discovery → design → build → test → production. The "Forward Deployed" framing means you work directly with internal HR customers, prioritize impact, and ship working software that automates real workflows.

## What You'll Do

- Own a project end-to-end (problem definition → design → build → ship) within the 12-week internship
- Build custom applications, integrations, and AI-powered workflows that automate HR processes
- Make technical decisions across data modeling, API integrations, application logic, and UIs
- Partner directly with HR stakeholders to map user journeys and prioritize roadmap
- Define success metrics (time saved, error reduction, adoption rates) and use data to iterate

## Required Skills

- Currently pursuing **degree in CS, Software Engineering, or related**
- Demonstrated ability to **build, test, debug, ship software** (apps, API integrations, automation tools) via projects, hackathons, or internships
- Hands-on experience with **AI-powered prototypes or workflows** using LLMs — including validating outputs, protecting sensitive info, knowing when human review is needed
- Proven ability to take scoped projects from ambiguous needs → milestones → delivery
- **Responsible generative AI use** with human oversight
