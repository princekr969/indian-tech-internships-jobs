## ✅ Eligibility & Selection

### Eligibility
- 🎓 **2027 Bachelor's or Master's graduate** in CS / IT / related
- 📅 **DSA + Java/Python/Go + cloud (AWS/Azure/GCP) + Linux/Networking**
- 💻 **1+ project with cloud infrastructure / DevOps**
- 🌍 **No prior full-time experience**
- 📊 **6.5+ CGPA** typical

### Selection Process

| Stage | Format | What It Tests |
|---|---|---|
| **1. Application** | Portal / on-campus | Resume + projects + CGPA |
| **2. Online Assessment** | HackerRank | DSA + coding (2-3 problems) |
| **3. Technical Interview (2 rounds)** | Virtual / on-campus | DSA + cloud + projects + system design |
| **4. HR Discussion** | Virtual | Role expectations + CTC |
| **5. Offer** | Via recruiting | — |

**Total timeline:** 4-6 weeks.
