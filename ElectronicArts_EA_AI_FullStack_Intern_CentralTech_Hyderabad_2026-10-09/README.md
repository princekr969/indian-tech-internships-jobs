## ✅ Eligibility & Selection

### Eligibility
- 🎓 **2027 Bachelor's or Master's graduate** in CS / IT / related
- 📅 **For AI: Python + ML frameworks + LLMs + RAG** | **For Full Stack: React/Node + TypeScript + cloud**
- 💻 **1+ project with AI/ML or full-stack web app**
- 🌍 **Interest in gaming a plus**
- 📊 **7.0+ CGPA** typical

### Selection Process

| Stage | Format | What It Tests |
|---|---|---|
| **1. Application** | Portal | Resume + projects + GitHub |
| **2. Online Assessment** | HackerRank | DSA + coding (2-3 problems) |
| **3. Technical Interview (2-3 rounds)** | Virtual | DSA + projects + system design + AI/ML |
| **4. Hiring Manager Round** | Virtual | Behavioral + EA values |
| **5. Offer** | Via recruiting | PPO based on intern performance |
