# Why Referrals Win (Read This First)

Stat: Referrals shortlist at **5–10× the rate** of cold applications. A 1000-person applicant pool might yield 10 shortlists; the same role via referral might yield 20 shortlists from 5 referrals.

| Channel | Avg Shortlist Rate | Avg Response Time |
|---|---|---|
| Cold application (no referral) | 1–3% | 4–8 weeks (or never) |
| With a referral | 10–30% | 1–3 weeks |
| Direct recruiter message | 20–40% | 3–7 days |

1. **LinkedIn search** — "Application Engineer at Google" or "SDE at American Express" — filter by India location.

# Pre-Application Checklist (For All 3 Roles)

Use this checklist before submitting any application:

```
[ ] Resume is ATS-friendly (PDF, ≤2 pages, no tables, no columns, no images)
[ ] Resume has clear header: Name | Email | Phone | GitHub | LinkedIn
[ ] Resume has quantified bullets (e.g., "Reduced API latency by 40% via caching")
[ ] Resume has 2-3 strong projects with tech stack, impact, GitHub link
[ ] GitHub profile pinned with top 3 repos (clean README for each)
[ ] LinkedIn profile matches resume (headline, summary, experience)
[ ] LeetCode / CP profile is public and shows 150+ solved
[ ] Cold email template personalized for each company
[ ] Cover letter / "Why this company" — 2-line answer ready
[ ] Referral obtained (preferred over cold apply)
[ ] Application submitted before deadline (most startup roles are rolling)
[ ] Follow-up email/DM scheduled for 7 days after apply (if no response)
```
