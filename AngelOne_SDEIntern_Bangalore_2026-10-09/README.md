## ✅ Eligibility & Selection

### Eligibility
- 🎓 **2027 Bachelor's graduate** in CS / IT / related
- 📅 **Backend: Java/Go/Python + low-latency systems + Kafka**
- 💻 **1+ project with real-time systems / trading / fintech**
- 🌍 **Interest in stock markets a plus**
- 📊 **6.0+ CGPA** typical

### Selection Process

| Stage | Format | What It Tests |
|---|---|---|
| **1. Application** | Portal | Resume + projects + GitHub |
| **2. Online Assessment** | HackerRank | DSA + coding (2-3 problems) |
| **3. Technical Interview (1-2 rounds)** | Virtual | DSA + backend + projects |
| **4. HR Discussion** | Virtual | Role expectations + stipend |
| **5. Offer** | Via recruiting | PPO based on intern performance |

**Total timeline:** 3-5 weeks.
