## ✅ Eligibility & Selection

### Eligibility
- 🎓 **2027 Bachelor's or Master's graduate** in CS / IT / related
- 📅 **Penultimate or final year** students eligible
- 💻 **Distributed systems + cloud (AWS/GCP) + 1+ production project**
- 🌍 **No prior full-time experience**
- 📊 **Strong academic record** (7.0+ CGPA typical, varies)

### Selection Process

| Stage | Format | What It Tests |
|---|---|---|
| **1. Application** | Careers portal | Resume + cover letter + projects |
| **2. Online Assessment** | HackerRank / HackerEarth | DSA + coding (medium-hard) |
| **3. Technical Phone Screen** | 45-60 min (CoderPad) | DSA + 1 system design |
| **4. Virtual Onsite (3-4 rounds)** | 45-60 min each | DSA + system design + behavioral + Atlassian values |
| **5. Hiring Committee** | Internal review | Cross-team calibration |
| **6. Offer** | Via recruiter | — |

**Total timeline:** 4-8 weeks. **Cooldown:** 6 months if rejected.
